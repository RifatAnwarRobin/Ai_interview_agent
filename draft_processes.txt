Structure of the system:
* Superbase for the free authentication process.
* N8N webhook to take input from streamlit.
* Response to the N8N webhook.
* Send response to PSQL node for saving raw data.
* Extract Job Description text from the input and convert to tabular format/vector embedding using LLM/ Minstral OCR API.
* Extracted Format will later be stored in PSQL/VectorDB(chromaDB)
* Make questions based on the formatted data(json/or any other format).
* Later the Evaluation part.

*Later created a table name raw_user_inputs to get input raw data from streamlit to postgres
CREATE TABLE raw_user_inputs (
    id SERIAL PRIMARY KEY,
    user_id UUID NOT NULL,
    input_type VARCHAR(50) NOT NULL,
    raw_text TEXT NOT NULL,
    difficulty VARCHAR(20) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    processing_status VARCHAR(30) DEFAULT 'pending'
);
